# Prompt: Plan the implementation

**When:** after the spec is approved, before any code.
**Mode:** plan mode / read-only.

```
Read docs/specs/<name>.md and the relevant code. Produce an implementation plan. Do NOT edit files.

The plan must contain:
1. Files to create/modify (with one-line reason each).
2. A sequence of small steps (each independently buildable and testable, each < ~150 lines).
   For each step: what changes, the test that proves it, and the command to run.
3. Interfaces/types/signatures introduced or changed.
4. Risks, unknowns, and anything that needs a human decision (dependencies, schema changes).
5. What you will NOT do (scope guard).

Flag any conflict between the spec and the existing code. Wait for my approval before implementing.
```
